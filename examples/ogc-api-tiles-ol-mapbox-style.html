--- layout: example.html title: OGC API – Tiles with a Mapbox Style shortdesc: Styling vector tiles from an OGC API – Tiles service with ol-mapbox-style. docs: > This example renders vector tiles from an OGC API – Tiles service, the BRT Achtergrondkaart (topographic background map) of the Dutch Kadaster.
The layer is styled with ol-mapbox-style, using the Mapbox style document from the OGC API – Styles endpoint of the same service.
The layer and its ol/source/OGCVectorTile source are created first, then applyStyle() adds the style. The updateSource: false option makes sure the style is only used for styling, and the OGC API – Tiles source of the layer is kept.
Finally the map is created with the styled layer. tags: "ogc, vector tiles, mapbox, ol-mapbox-style" ---
