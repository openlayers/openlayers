--- layout: example.html title: NDVI from a COG with a raster source shortdesc: Running a pixel operation over multi-band data tiles. docs: > This example computes the Normalized Difference Vegetation Index (NDVI) from two Sentinel 2 bands using an ol/source/Raster operation. The raster source takes a GeoTIFF data tile source as input, samples it at its native tile resolution, and runs a pixel operation that maps NDVI to a color ramp. Compare with the NDVI from a Sentinel 2 COG example, which uses a WebGL layer style instead. Move the pointer over the map to read the NDVI value from the source's getData() lookup. tags: "cog, ndvi, raster" ---
