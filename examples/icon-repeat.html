Static `Point`, `MultiPoint`, `MultiLineString`, `Polygon` (both `placement: 'line'`, which uses only the exterior ring, and the default `placement: 'point'`, which uses the polygon's interior point), and `rotateWithLine: false` (icons repeated along a line or polygon ring without following its direction) are shown for comparison; draw a line string to see the icon placed and rotated along it interactively. tags: "icon, line, polygon, vector, draw, rotation, repeat" ---
