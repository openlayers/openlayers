--- layout: example.html title: WebGPU Reprojection shortdesc: GPU reprojection of WebGPU raster tiles, with vector features in the view CRS. docs: >

Use the CRS dropdown to change the projection of the view. Raster tiles are reprojected at render time with a CPU-built mesh (source-tile textures, GPU draw). Vector features stay in EPSG:4326 and are densified, triangulated in the view CRS, and clipped — the same approach as WebGL reprojection. There is no silent fallback if navigator.gpu is missing.

The labeled data tiles are in EPSG:4326. The basemap is in EPSG:3857. Vector ecoregions stay in EPSG:4326 and are reprojected when drawing.
