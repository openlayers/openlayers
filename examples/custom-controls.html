--- layout: example.html title: Custom Controls shortdesc: Shows how to create custom controls. docs: > This example creates a "rotate to north" control with an inline SVG north arrow. The control's render method rotates the arrow together with the map, so it always points north, and hides the control with the ol-hidden class when the map is not rotated. The control replaces the default ol/control/Rotate control, which is left out of the map's controls. Use Alt+Shift+Drag to rotate the map. tags: "custom, control, rotate, north, svg" ---
