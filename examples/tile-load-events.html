--- layout: example.html title: Tile Load Events shortdesc: Example using tile load events. docs: > Image tile sources fire events related to tile loading. You can listen for tileloadstart, tileloadend, and tileloaderror type events to monitor tile loading progress. This example registers listeners for these events and renders a tile loading progress bar at the bottom of the map. The progress bar is shown and hidden according to the map's loadstart and loadend events. tags: "tile, events, loading" ---
